## Description

[Nest](https://github.com/nestjs/nest) framework TypeScript starter repository.

## Project setup

```bash
$ npm install
```

## Compile and run the project

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Run tests

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```

## Banco de dados

A persistência usa Prisma com PostgreSQL. O banco é o Neon, provisionado pelo Marketplace da Vercel.

### Configuração local

Copie o `.env.example` para `.env` e preencha com as connection strings do Neon:

```bash
$ cp .env.example .env
```

- `DATABASE_URL` é a string com pooling (PgBouncer), usada pela aplicação em tempo de execução
- `DATABASE_URL_UNPOOLED` é a conexão direta, usada pelo Prisma Migrate

Depois crie as tabelas:

```bash
$ npm run prisma:migrate
```

Outros comandos disponíveis:

```bash
# regenerar o Prisma Client
$ npm run prisma:generate

# aplicar migrations já existentes (produção)
$ npm run prisma:deploy

# abrir o Prisma Studio
$ npm run prisma:studio
```

## Deploy na Vercel

A Vercel tem suporte zero-config a NestJS: ela detecta o `src/main.ts` como entrypoint e transforma a aplicação em uma Vercel Function com Fluid compute. Não é necessário `vercel.json` nem um handler em `api/`.

1. Instale a integração do [Neon](https://vercel.com/marketplace/neon) no projeto da Vercel. Ela injeta `DATABASE_URL` e `DATABASE_URL_UNPOOLED` automaticamente nas variáveis de ambiente.
2. Rode `npm run prisma:migrate` com o `.env` apontando para o banco do Neon, para criar as tabelas e versionar a migration em `prisma/migrations`.
3. Faça o commit da pasta `prisma/migrations` e conecte o repositório em [vercel.com/new](https://vercel.com/new), ou rode `vc deploy`.

O `prisma generate` roda no `postinstall`, então o Prisma Client é gerado antes do build na Vercel. Migrations não são aplicadas no build: use `npm run prisma:deploy` sempre que houver uma migration nova para levar ao banco de produção.
